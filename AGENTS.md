# Fusion 360 workflow

- Before changing geometry or features, activate the individual component that owns them and verify that it is the active component. Repeat this whenever switching components.
- Make CAD changes parametric. Use clearly named user parameters with units and helpful descriptions for adjustable dimensions, hole patterns, offsets, clearances, and feature sizes. Drive sketches and features with parameter expressions, and reuse shared parameters for mating geometry.
- Use computer use to inspect the live Fusion workspace before editing, at meaningful modeling milestones, and after changes. Combine visual checks with CAD measurements to verify placement, alignment, clearances, and the final result.
